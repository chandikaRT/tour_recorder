# tour_recorder

Odoo 17 Enterprise recreation of the **Custom Tour Recorder / Interactive User
Guide** app — record no-code interactive guides, assign them to users, play them
through Odoo's native tour engine and track completion progress.

The module lives in [`custom_tour_recorder/`](custom_tour_recorder/) — see its
[README](custom_tour_recorder/README.md) for features, install steps and the
Odoo 17 porting notes.

`Screenshots/` contains the reference UI of the original app that this
implementation was built from.
